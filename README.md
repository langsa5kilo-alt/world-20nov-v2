# World Picture, 20 November 2026

A deterministic, dark newspaper front page generated with Python and Pillow. It presents 45 plausible world-news reports across seven regions, with flat vector illustrations, a schematic map, date audit, and strict layout assertions.

Run `python3 gen.py` to produce `entry.png`. The TypeScript entry point copies that image into `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`.
